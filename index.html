A few little details

Questions from the crypt.

Can I use this on my phone?

Yes. The page is designed to adapt to mobile and desktop screens. The invitation preview updates as you edit the form.

Does it create a permanent invitation link?

Not in this first prototype. For now, you can download a preview image or copy the invitation text. Permanent hosted links, RSVP collection, and guest management need a backend.

Can I buy the Haunted Mystery today?

The mystery is a planned add-on, not a finished paid product yet. Checkout and game delivery will need to be implemented before launch.
