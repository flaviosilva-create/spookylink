Can I use this on my phone?

Yes. The page is designed to adapt to mobile and desktop screens. The invitation preview updates as you edit the form.

Does it create a permanent invitation link?

SpookyLink creates a shareable invitation URL that carries the event details in the URL itself, plus a paid downloadable invitation image. It does not store invitations on a server or include RSVP collection or guest management.

Haunted Mystery is a six-chapter browser game with connected clues, an evidence file, hints, a final deduction, and a story ending. After checkout is verified, the game unlocks in the same browser.
